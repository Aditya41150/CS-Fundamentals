## Suggested Weekly Load

Aim for **2–3 focused hours/day, 6 days/week**:

- 60–90 min DSA
- 30–45 min CS fundamentals
- 20–30 min SQL / interview practice / revision
- 10 min progress tracking

## What Counts as “Done”

A topic is interview-ready when you can:

- explain it without reading notes;
- handle basic follow-up questions;
- solve or reason through a representative problem; and
- connect it to a real software example.

## Resource Rule

Use the personalized roadmaps in this repository as the **source of truth for what to study**. The original PDFs, notes and question banks are references to use when a roadmap points you to them.

You do **not** need to read every resource in the repository.
