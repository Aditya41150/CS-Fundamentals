# OOP Roadmap — Interview First

Study OOP as a set of ideas you can explain and implement, not as definitions to memorize.

## 1. Core Building Blocks
- Classes and objects
- Attributes and methods
- Constructors
- `this` / `self`
- Instance vs class members

Use: [OOP Interview Questions](../OOPs/OOPs-Interview-Questions.pdf)

## 2. Four Core Principles
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism

For each: definition → why it exists → simple code example → real-world example → trade-off.

## 3. Relationships and Design
- Composition vs inheritance
- Association / aggregation basics
- Interfaces / abstract classes
- Dependency and loose coupling

## 4. Language-Specific Practice
Choose the language you are most likely to interview in.
- Java: [OOP Concepts in Java](../OOPs/OOPS-Concepts-in-Java.pdf)
- Python: [Python OOP](../OOPs/Python-OOP.pdf)
- JavaScript: [Principles of OOP in JavaScript](../OOPs/Principles-of-OOP-JavaScript.pdf)
- C++: [OOP in C++](../OOPs/OOP-in-CPP.pdf)

## 5. Common Interview Questions
- Class vs object
- Encapsulation vs abstraction
- Overloading vs overriding
- Compile-time vs run-time polymorphism
- Composition vs inheritance
- Interface vs abstract class
- What makes a class immutable?
- What is method overriding used for?

## Interview-Ready Test
Pick one principle and explain it without notes, write a small example, explain what happens at runtime, and answer two follow-up questions.
