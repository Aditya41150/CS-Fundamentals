# DBMS + SQL Roadmap — Interview First

Use this roadmap as the filter for the existing DBMS and SQL resources. Study one topic at a time and practice by writing queries or explaining concepts aloud.

## 1. SQL Foundations
- SELECT, WHERE
- ORDER BY
- DISTINCT
- LIMIT / TOP-style result limiting
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX

Reference: [Complete SQL Cheatsheet](../DBMS-and-SQL/Complete-SQL-Cheatsheet.pdf)

## 2. Grouping and Joins
- GROUP BY
- HAVING
- INNER JOIN
- LEFT JOIN
- RIGHT / FULL JOIN concepts
- Self join
- Joining multiple tables

Practice reference: [SQL Tutorial](../DBMS-and-SQL/SQL-Tutorial.pdf)

## 3. Subqueries and Advanced SQL
- Scalar and correlated subqueries
- EXISTS / NOT EXISTS
- CTEs
- CASE
- Window functions: ROW_NUMBER, RANK, DENSE_RANK

Interview practice: [Top 50 SQL Interview Questions](../DBMS-and-SQL/Top-50-SQL-Interview-Questions.pdf) and [LeetCode SQL](../DBMS-and-SQL/LeetCode-SQL.pdf)

## 4. Relational Database Fundamentals
- Tables, rows, columns
- Primary and foreign keys
- Candidate / alternate keys
- Constraints
- Relationships and cardinality

Reference: [DBMS Notes](../DBMS-and-SQL/DBMS-Notes.pdf)

## 5. Normalization
- Functional dependencies
- 1NF, 2NF, 3NF
- BCNF basics
- Insert / update / delete anomalies
- When denormalization can be useful

## 6. Transactions and Concurrency
- ACID properties
- Transaction states
- COMMIT / ROLLBACK
- Isolation levels
- Dirty read, non-repeatable read, phantom read
- Locks and basic concurrency control

## 7. Indexing and Query Performance
- What an index is
- Why indexes improve reads
- Trade-offs for writes and storage
- Clustered vs non-clustered concepts
- B-tree / B+ tree intuition
- When indexes may not help

## 8. Interview Revision
Use:
- [100 DBMS Interview Questions](../DBMS-and-SQL/100-DBMS-Interview-Questions.pdf)
- [SQL Interview Questions and Answers](../DBMS-and-SQL/SQL-Interview-Questions-and-Answers.pdf)
- [Additional SQL Interview Q&A](../DBMS-and-SQL/SQL-Interview-QA-2.pdf)

## Study Rule

For SQL, spend more time **writing queries** than reading syntax. For DBMS theory, learn the reason behind each concept and be ready with an example.

A topic is ready only when you can explain it simply and answer follow-up questions without notes.
