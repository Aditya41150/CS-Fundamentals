# Software Engineering Roadmap — Interview First

- Design
- Implementation
- Testing
- Deployment
- Maintenance

## 3. Testing
- Unit testing
- Integration testing

- Single responsibility

- Error handling
- Logging
- Documentation

## 5. Engineering Interview Questions
Use [SE Interview Questions](../Software-Engineering/SE-Interview-Questions.pdf).

Common questions:
- What happens in a pull request?
- Merge vs rebase?
- Unit vs integration testing?
- How do you debug a production issue?
- What makes code maintainable?

## Interview-Ready Test
Be able to describe how you would take a small feature from requirement to code, tests, code review and deployment, including how you would handle a bug found after release.
