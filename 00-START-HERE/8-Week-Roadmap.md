# 8-Week Roadmap

This is the main study plan for preparing for **fresher software-development interviews**.

The goal is not to finish every PDF in the repository. The goal is to become interview-ready by studying the highest-value topics first and continuously practicing DSA, SQL and interview communication.

## Weekly Plan

| Week | Main Focus | Secondary Focus |
|---|---|---|
| 1 | DSA foundations | OOP basics + SQL basics |
| 2 | Arrays, strings, hashing | DBMS fundamentals |
| 3 | Linked lists, stacks, queues | Operating Systems |
| 4 | Trees, BST, recursion, backtracking | Computer Networks |
| 5 | Graphs + greedy | SQL + transactions/indexing |
| 6 | Dynamic programming + mixed DSA | OOP + system design basics |
| 7 | DSA interview sets | OS/CN/DBMS rapid revision |
| 8 | Mock interviews + revision | Projects + HR/behavioral |

## Daily Structure

**60–90 min — DSA**

Learn one pattern or topic, then solve problems without immediately looking at solutions.

**30–45 min — CS fundamentals**

Rotate DBMS, OOP, OS, CN and system design according to the week's plan.

**20–30 min — SQL / interview practice**

Practice SQL, explain concepts aloud, or answer interview questions.

**10 min — Review**

Update the progress tracker and write down mistakes or concepts that need revision.

## Rules

1. Prefer understanding over memorization.
2. For DSA, learn the pattern before collecting lots of problems.
3. For CS fundamentals, practice explaining concepts in simple language.
4. Keep a short mistake log.
5. Revisit weak topics instead of repeatedly reviewing topics you already know.
6. Use the original PDFs and notes in this repository as references, not as mandatory reading lists.

## Interview-Ready Standard

A topic is considered ready when you can explain it without notes, answer common follow-ups, solve or reason through a representative problem, and give a practical software example.

## End-of-Week Check

At the end of every week, answer:

- What topics can I explain confidently?
- Which DSA patterns can I solve without help?
- Which SQL queries can I write from scratch?
- What mistakes did I repeat?
- What should I revise next week?
