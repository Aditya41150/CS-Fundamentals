# Daily Checklist

Use this as a simple daily routine. The aim is consistency, not studying for hours.

## Every Study Day

- [ ] DSA: 60–90 minutes
- [ ] CS fundamentals: 30–45 minutes
- [ ] SQL / interview practice: 20–30 minutes
- [ ] Review mistakes and update progress: 10 minutes

## DSA Checklist

- [ ] Learn/revise today's pattern
- [ ] Attempt problems independently
- [ ] Write down mistakes
- [ ] Re-solve at least one previously missed problem

## CS Fundamentals Checklist

- [ ] Study one focused topic
- [ ] Explain it aloud without notes
- [ ] Answer 2–3 interview-style follow-up questions
- [ ] Connect the concept to a practical software example

## SQL / Interview Checklist

- [ ] Write at least one SQL query from scratch OR answer interview questions
- [ ] Practice explaining one project/concept clearly

## Before Finishing

- [ ] Update `Progress-Tracker.md`
- [ ] Record anything I need to revise
- [ ] Decide tomorrow's first task

## Minimum Day

On busy days, do this instead of skipping completely:

- [ ] 30 min DSA
- [ ] 20 min fundamentals
- [ ] 10 min revision
